# 采购配方的炼金时间

按用户指定的显示规则计算：取单个配方已匹配材料的 Steam `cooldown_ends_at` 最晚值，向上取整到整点（正好整点时保持原时间）。

例如北京时间 2026-10-25 22:12 → 2026-10-25 23:00。例如 19:00 保持 19:00，18:42 取到 19:00。不额外增加 7 天，也不从核对入库时间开始计算。

- 采购管理统一按采购批次展示未汰换配方，已入库与未入库配方保留在同一批次；不再单设“可炼金配方”和“已采购完成”入口。
- 单个配方材料全部入库后，在该配方标题旁显示炼金时间；未全部入库的配方不显示。
- 仅使用配方实际匹配的 Steam 资产 ID，不把其他库存饰品算入。
- 多个配方分别计算并显示各自的炼金时间，采购批次标题不显示炼金时间。
- 首次全部入库时计算并保存炼金时间；后续点击“核对库存”时重新检查本地库存中的冷却信息并保存。切换页面、读取记录、展开配方只显示已保存的结果，不再读取库存或重新计算冷却时间，没有定时轮询。
- 若所有材料都已明确可出售且无冷却，则显示“可炼金”；缺少可识别的冷却信息时显示“待刷新 Steam 库存确认”，不会用入库时间估算。
- 重新采购、撤销入库或跨账号转移时，清除受影响材料的旧冷却绑定。保留原有入库记录。

此规则用于采购管理的时间显示。实际汰换及 ECO 合炉发布仍会另行校验材料库存与 Steam 冷却状态。
