# 按日期管理采购配方

- 采购管理按配方加入采购的本地日期分组，不区分原批次及账号；每炉显示账号名和当天编号。
- 采购管理与已炼金的日期默认收拢，手动展开状态在本次页面会话内保留。
- 日期旁提供删除当前分类所显示配方的操作；采购日期旁另有核对库存，每个账号只核对一次，使用最近的本地库存缓存。
- 日期收拢时仍展示账号、材料状态汇总和总成本；采购日期区域提供材料筛选、统一标记/撤销已买、批量修改账号及查看材料。批量操作只针对当天当前显示的配方，不改其他日期或归档记录。
- 已炼金按完成时间分组。旧记录没有完成时间时，使用原采购日期。
- 核对库存时，某炉 10 件材料均已入库、绑定 10 个不同资产且全部不在该账号库存中，则自动归入「已炼金」，按发现全部离库的日期分组，标注「全部离库已归档」。部分离库、未全部入库或资产绑定不完整的配方不会自动归档。此标记不生成真实 Steam 汰换事件，可手动恢复。
- 添加采购只选收货账号，自动使用当天记录，不再填写或选择批次。
- 每炉可独立查看材料、筛选、标记已买、核对库存、修改账号或删除。已炼金配方保留查看和单炉删除。
- 修改账号保留采购日期，旧账号的库存匹配按原规则撤销。
- 已有文件保持原有结构和精确材料关联，按日期统一展示，无需迁移或覆盖历史采购数据。
